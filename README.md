### 🎨 Core Features & UX
- **🌓 Dynamic Theme System**: A custom-built Dark/Light mode toggle that persists across page navigations.
- **📱 Fluid Responsiveness**: Designed using a mobile-first approach with CSS Flexbox and Grid.
- **📁 Multi-Page Navigation**: Includes Home, Projects, and Hobbies pages.
- **✨ Micro-Interactions**: Smooth scrolling and animations for enhanced engagement.

---

### 🛠️ Technical Architecture & Stack
- **Structure**: Semantic HTML5 for better accessibility and SEO.
- **Styling**: Vanilla CSS3 with custom variables for the theme engine.
- **Logic**: Vanilla JavaScript for DOM manipulation.
